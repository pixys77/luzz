ENG:                                                                                                                                         
**luzz** is a fast fuzzing orchestrator written in `Rust`.
The entire fuzzing process runs in `Docker` containers located in `/targets`.
RU:
**luzz** - это быстрый оркестратор фаззинга, написанный на `rust`.            
Весь процесс фаззинга запускается в `Docker` контейнерах, которые находятся в `/targets`.
